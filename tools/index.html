A reproducible workflow

Model the expected response, estimate parameters from a measured trace, and validate the run's data. Each tool preserves numerical values and exports its inputs or configuration alongside the result.

Every tool includes synthetic examples, numerical tests, and documented limits. Optical models use idealized assumptions; fit uncertainties are local approximations. Check convergence and inspect the model before interpreting a result.
